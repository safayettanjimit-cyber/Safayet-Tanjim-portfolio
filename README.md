# Safayet Tanjim — Portfolio

A responsive personal developer portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio page
- `style.css` — responsive styling and animations
- `script.js` — menu, scroll reveal, cursor glow and dynamic year

## Deploy with GitHub Pages

1. Create a GitHub repository named `safayettanjim002.github.io`
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. Your site should become:
   `https://safayettanjim002.github.io`
